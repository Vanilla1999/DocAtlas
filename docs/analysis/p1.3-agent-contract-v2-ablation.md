# P1.3 — Agent Contract v2 ablation

Status: **closed with an ablation decision; no production API change accepted**.

P1.2 found three first-divergence classes in the retained 0/11 model run.
P1.3 tests whether the three proposed contract simplifications actually address
those first causal breaks.

## Variants

### 1. Add `working_path` to the public MCP arguments — rejected

The model already received a non-empty `working_path` in every public frozen
task. Duplicating that value in a second public schema does not itself resolve
the exactly-one-of `module` / `module_path` action error.

Counterfactual first divergences prevented: **0/11**.

### 2. Conservative server-owned module inference — promising, inconclusive

The evaluation-only transform infers a module only when the supplied working
path belongs to exactly one reviewed module root. It fails closed on traversal,
outside-root paths, overlapping roots and nested ambiguous roots.

It can counterfactually replace the repeated selector-cardinality failure for
all **8/8** affected tasks without changing false-support or contamination in
the provider-free safety checks.

This is not enough to merge the behavior into production. A fresh same-model
installed-MCP run is still required to prove that autonomous evidence
acquisition improves rather than merely moving the failure elsewhere.

Decision: **deferred experiment**, not accepted runtime behavior.

### 3. Opaque continuation token — rejected for the observed failures

All 11 first divergences occur before a valid continuation exists:

- eight before the first accepted call;
- two at first-call retrieval/proofability;
- one at first-step ordering.

Counterfactual first divergences prevented: **0/11**.

A continuation token may be useful for another measured lifecycle problem, but
P1.2 does not provide that evidence.
