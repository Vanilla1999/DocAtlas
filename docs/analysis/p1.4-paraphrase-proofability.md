# P1.4 — Paraphrase and proofability robustness

Status: **closed with provider-free measured evidence**.

This protocol separates two questions that were previously easy to conflate:

1. did the query plan expose enough concepts to discover the candidate source;
2. did the final evidence selector prove every mandatory obligation strongly
   enough to return `supported`?

A candidate hit is therefore never counted as documentary support by itself.

## Corpus

Fourteen frozen cases cover:

- exact identifiers;
- behavior questions;
- requirements questions;
- project policy questions;
- symbol typos;
- natural-language aliases;
- negative controls.

Exact identity and core behavior cases are hard acceptance cases. Broader
requirements/policy variants, typos and aliases are measured independently so
a recall gap cannot be hidden by weakening final support precision.

## Safety boundary

Every negative control must remain unsupported. The report also rejects:

- support without selected evidence;
- a required discovery miss;
- a required core support miss;
- absolute local paths;
- claims that the provider-free protocol changed production runtime or proved
  autonomous Agent Truth.

## Decision

P1.4 closes when the frozen report is reproducible, required core cases pass,
and negative-control false support is zero. Typo and alias results remain
measured evidence rather than an implicit requirement to broaden authority or
relax `insufficient_evidence`.

No production retrieval, public MCP schema or support rule is changed by this
slice. The next evidence question is P1.5: whether mixed source roles preserve
claim-local provenance under conflict.
