# P1.2 — Agent Developer 0/11 first-divergence atlas

Status: **closed with historical evidence**.

This analysis explains the first divergence in every task of the frozen
Agent Developer model report. It does not claim that the current installed
MCP harness was exercised by a fresh autonomous model run: the repository does
not currently provide `OPENAI_API_KEY`, and the retained 0/11 report predates
P1.1's installed-wheel boundary.

## Inputs

- public task contract: `eval/agent_developer_v1/tasks.json`;
- evaluator-only expected trajectories:
  `eval/agent_developer_v1/expected_trajectories.json`;
- retained model result:
  `eval/agent_developer_v1/results/model-benchmark.json`;
- machine-readable result:
  `eval/agent_developer_v1/results/first-divergence-atlas.json`.

The gate binds the three source files by their Git blob identities and derives
the committed atlas again on every pull request.

## Result

| First failure class | Tasks | Interpretation |
|---|---:|---|
| `module_selector_cardinality` | 8 | The model action failed the exactly-one-of `module`/`module_path` host contract before any context retrieval. |
| `retrieval_query_drift` | 2 | Scope selection was correct, but a broad paraphrase lost the exact named fact and produced `insufficient_evidence`. |
| `trajectory_order` | 1 | The dependency lane was attempted before the required module-local evidence lane. |

Safety outcomes remained clean:

```text
false_supported = 0
forbidden_source_contamination = 0
```

## Evidence limit

For the eight selector failures, the historical report retained the validator
message but not the rejected action. Therefore the atlas proves the repeated
cardinality boundary, but cannot distinguish whether a row omitted both
selectors or supplied both. That distinction requires a fresh P1.1 installed
model report which records every attempted call.

## Product decision

P1.2 closes the diagnosis step, not Agent Truth itself.

The repeated failures justify P1.3 ablations, but do not pre-authorize a public
API change. In particular:

- adding `working_path` to the public MCP schema is not accepted merely because
  module selection failed;
- server-owned scope/module inference must be tested against the same frozen
  tasks and safety metrics;
- a continuation token cannot address failures that occur before the first
  accepted call.

Until those ablations are complete, the public three-tool contract and current
retrieval/support semantics remain frozen.
