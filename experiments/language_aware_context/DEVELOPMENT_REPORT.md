## Where the HTTPX fact is lost

For `httpx-disable-client` with the supplied lookup, the complete Client example
is present in retrieved candidates (lines 30–40), the query window, qualified
fragments, and the projector input. It is absent from final visible sources.
The final packet includes unrelated environment-variable configuration, a custom
60s/10s timeout example, and prose from lines 32–33 without the `timeout=None`
example. The original-only packet contains the required complete example.

The first established loss boundary is downstream of the projector input, within
selection/projection/budget handling; a specific culprit function is not proven.
Adding neighbours or translating more queries is not an established fix.
For the default-timeout original query, the fact exists in the index (lines 1–5)
but is absent from the captured retrieved candidates. These are different failures.
Only direct snippet/display_text fields were counted; a raw document attached to
reference metadata is not model-visible evidence. Repeated trace occurrences do
not count as distinct documents.

## Profile prototype

`source_profile.py` extracts disjoint prose ranges from authorised source snapshots,
excluding code and metadata conservatively. Measurement-only cleaned text is never
used as evidence. The caller must supply resolver-authorised scope information.
Snapshot mismatch and unsupported/ambiguous text fail closed to no hint/`und`.
Tests include mixed sources, a minority language, fences, source offsets and changed
extractor revisions. Production resolver/cache integration is not implemented.

The draft detector classifies about 42.3% of Typer prose letters as EN and 57.7%
as unknown; HTTPX is 61.5% EN and 38.5% unknown. These are classifier buckets,
NOT true corpus language percentages or measured confidence. Both suggest EN;
neither profile was passed to a planner in this probe. Detector accuracy and its
incremental usefulness remain unmeasured. Do not tune it to force EN=100% here.

The focused baseline is the unmodified e384 source archive; the candidate differs
only in experiment/tests/workflow. This is not a full main-versus-candidate gate.

fixed here. Missing local dependencies are environment blocks, not product bugs.
Other pre-existing CI failures are not classified as old/new without a paired run.

## Decision

T1 now has real development evidence; H1/H2/H3 remain unmeasured. Keep the PR draft.
Next, preserve a regression case for the lost HTTPX Client example before choosing
an assembly change. A–E needs real agent-generated lookups, new RU/EN/mixed scopes,
independent labels, frozen parameters and blind answer evaluation. Do not substitute
these manually selected lookups for that baseline. Raw traces remain outside Git.
Production/MCP code, v3, model thresholds and P0 are unchanged. No merge/activation.
