## Что именно реализовано в последнем patch

`docmancer/docs/application/joint_context_candidates.py`: добавлена обработка границ пункта списка. Цитата завершается по исходным координатам вместе с lazy continuation и вложенными пунктами. В source options обычный bullet-only раздел больше не получает обязательный вариант «весь раздел». Для смешанных prose/code разделов сохранён консервативный вариант, поскольку одно завершённое предложение не доказывает ненужность соседнего правила. Нумерованная последовательность остаётся целым ranking-блоком; для закрытия конкретной цитаты доступны границы её пункта. Это эвристика структуры, её семантическую безопасность необходимо проверить, а не принять на веру.

`docmancer/docs/application/joint_context_selection.py`: при равной структурной полноте выбирается меньший валидный публичный пакет; число объединений и наличие дополнительного введения больше не имеют собственной премии. Ограничение вычислительного перебора не равно лимиту ответа; новый потолок токенов не вводился.

Для host_lookup разрешено завершать уже допущенные фрагменты. Whole-section/intro/envelope расширение туда не добавлено. Проверки исходных диапазонов, бюджета, scope/version и query coverage сохранены; контекст остаётся retrieval-only. Нет дополнительного поиска, автоматического retry, пересказа цитат, новой модели, зависимости, миграции или схемы DTO.

## Основные открытые риски

Структурно соседние пункты могут быть семантически связаны. Already-admitted oversized seeds защищены от удаления. Смешанные разделы всё ещё бывают избыточны. Literal admission отбрасывает часть подходящих перефразированных фактов. Непустой retrieval-only пакет не гарантирует полный ответ. Все 50 вопросов на одном корпусе уже известны разработке. Lookup-фразы выбраны вручную и не доказывают работоспособность универсальной retry-политики.

Не внедрены: семантический reranker, XProvence/SWE-Pruner/LLMLingua-2, совместный нейронный sentence pruning, автоматический fallback, сжатая новая схема provenance или решение 12 direct-отказов.

## Сырьё и воспроизводимость

Манифест содержит archive IDs, run IDs, SHA-256 и исходные commits. Сохранённые JSON включают полные ответы, diagnostics и same-call snapshots. Сначала сравни head.txt и hash, затем независимо пересчитай факты. Для визуального разбора достаточно нескольких проблемных payload; весь 16-MB JSON не нужно помещать в prompt.

Коммит review-пакета не запускает новый измеренный эксперимент в рамках подготовки отчёта. Автоматически стартовавший CI после documentation-only push, если такой будет, имеет другой HEAD и не подменяет приведённый exact-head run.
