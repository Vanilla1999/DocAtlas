# Зафиксированный корпус: 40 вопросов, Mini и контроль без модели

## Происхождение

Для нового парного сравнения выбран **весь** исторический набор
`eval/scientific_validation40`, без отбора вопросов по результатам:

| Тип вопроса | Количество |
| --- | ---: |
| Полностью ответимый в выбранных документах | 24 |
| Частично ответимый | 8 |
| Неответимый | 8 |
| Всего разных вопросов | 40 |

Пять семейств — Black, Poetry, Textual, Vite и ESLint — содержат по восемь
вопросов. Это исторически открытый набор для повторного сравнения, а не новый
слепой holdout. Вопросы не сформированы по выводу нынешнего admission или Mini.

`questions.json`, `gold_spans.json`, `source_plan.json` — побайтовые копии
одноимённых исходных файлов. Их origin paths, bytes и SHA-256 сохранены в
`source-manifest.json`.

## Исходные документы

В `sources/<family>/` сохранены все 15 полных Markdown-файлов исходного source
plan. Использованы точные upstream commit SHA, не текущие ветки. Преобразований
текста нет; внешние include directives не раскрывались. Пять соответствующих
MIT-лицензий сохранены в `licenses/<family>/LICENSE`.

Все 20 зафиксированных скачиваний успешны. Загружено 243623 байта:
238209 байт документов и 5414 байт лицензий. Wall time восстановления —
25,738187 секунды. Манифест содержит URL, commit, размер, SHA-256, HTTP status,
время и длительность каждого скачивания. Отдельный предварительный read-only
availability probe одного Black-файла также записан в учёте; его ответ не был
сохранён, и он не используется как источник восстановленных bytes.

## Проверка oracle до запуска

`gold-span-audit.json` связывает каждую из 32 документированных частей с точным
текстом, SHA-256 источника, SHA-256 quote, line и char coordinates. Все диапазоны
находятся в границах восстановленных документов. Независимый автор корпуса
прочитал все 32 диапазона вместе с исходными вопросами и дополнительно поискал
в выбранных файлах якобы отсутствующие сведения. Исполнения нового продукта,
моделей или индексации при этой проверке не было; новые ответы не открывались.

Замечания записаны без изменения вопросов и эталонов:

- **V40-E05:** gold содержит путь с `jiti >=2.2.0`, но ниже в том же документе
  описан экспериментальный native путь для Node.js >=22.13.0 без `jiti`.
  Вопрос не задаёт версию Node.js. При семантической оценке нельзя считать
  `jiti` безусловной необходимостью для любого Node.js. Точное время overhead
  по-прежнему отсутствует, исторический `partial` сохраняется.
- **V40-V06:** код 403 указан для условия `fs.allow` при `fs.strict`, но это не
  явная гарантия для отдельно запрошенного `fs.deny`. Переносить число между
  этими отношениями нельзя; исторический gap не изменён.
- **V40-P04, V40-B04:** исходные gold ranges заканчиваются внутри code fence
  или поясняющего предложения. Это границы измеряемого oracle, а не утверждение
  структурной полноты. Нужное правило находится в указанном исходном диапазоне;
  oracle не сокращался и не расширялся.

Gold spans иногда включают заголовки, примеры или соседние объяснения. Полное
буквальное покрытие всего gold диапазона — консервативный показатель доставки
источника. Оно не тождественно правильности будущего ответа. Сокращать oracle
после просмотра нового вывода нельзя; семантическая оценка может записываться
отдельно с собственным обоснованием.

## Границы измерения

Восьми частичным вопросам разрешено доставить документированную часть. Отсутствие
ответа на вторую часть не превращает полезный источник в полностью нерелевантный.
Для восьми неответимых вопросов сохраняется строгий empty-source критерий.
Правильный будущий отказ генератора не исправляет нарушение этого контракта.

Oracle и тип ответимости не передаются ranker. Входы ranker должны содержать
только исходный пользовательский вопрос и реальные найденные кандидаты.
Подготовка, admission, retrieval, бюджет и финальная сборка одинаковы в паре.
Настройки и код фиксируются до результатов. После запуска этот набор не
используется для добавления условий под провалившиеся вопросы.

Восстановление выполнил отдельный агент, который не менял runner, production
код или тесты и не запускал модели. Итоговые измерения и их ledger создаёт
координатор отдельно от этих данных.
