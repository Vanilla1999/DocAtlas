# Harbour dashboard

The dashboard presents derived observations and is not a control channel for receivers.

## Display

The display rounds water levels to centimetres, highlights delayed stations, and offers a map with a selectable timezone. Hiding a station on the map does not pause its receiver or change export membership.

## Refresh

Browser refresh requests can be repeated freely. They do not replay journal records. Cached display points expire after ten minutes even when original observations remain in storage.
