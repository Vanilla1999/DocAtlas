# Terra 6.1 low: 20 вопросов к `main`

## Граница проверки

- Код продукта: чистый `main` на `ea9a56aff149d1314478c7a6c0a7dfad0f40aa3e` (шаг 5). Это **не** проверка следующего коммита с этим отчётом.
- Источники: замороженный корпус L0 из 19 документов коммита `3d21bfea`; это не индекс документации текущего дерева. Проверены первые 20 dev-вопросов из `questions.json`: 10 тем на русском и английском. Holdout не использован; этот срез не является независимым holdout или полным gate.
- Получение контекста: реальные `prepare_docs` и `get_docs_context` через stdio MCP, изолированное локальное хранилище, один сервер, `--jobs 1`, без наблюдателя; `DOCATLAS_OFFLINE=1`, `DOCATLAS_AUTO_VECTORS=0`, без экспериментальных флагов. Русские вопросы передавались с запечатанным английским `search_question`.
- Ответ: каждый текст ответа MCP отдельно передан `openai/gpt-6.1-terra#low` через `opencode run`, вместе с исходным вопросом и требованием отвечать только по приложенной выдаче. Это не автономный агент с подключённым DocAtlas MCP: вызовы retrieval сделал раннер; модель не вызывала инструменты. Первый запуск модели через дочернего агента не состоялся (HTTP 403), запуск через CLI завершился для всех 20 вопросов.
- Счётчик ниже — **дословные эталонные факты, видимые в доставленных источниках**, по `score.py` и запечатанному `oracle.json`; не оценка семантики ответов модели. Аномалий источников оценщик не обнаружил. Все упомянутые моделью `ev-…` refs проверены на наличие в соответствующей MCP-выдаче, но это не автоматическая проверка каждой интерпретации.

## Воспроизведение и сохранность материалов

Раннер: `eval/blind_project_context/run.py`, выбор `--split dev --corpus L0 --jobs 1 --no-observer --keep-work` с двадцатью `--case` (от T01-ru/T01-en до T20-ru/T20-en в порядке `questions.json`). Для исходной машины потребовалось разрешить серверу использовать установленные пользовательские Python-пакеты при изолированном `HOME`; код продукта не менялся. `score.py OUT` сверяет строки, пути и spans с запечатанными свидетелями. Для ответа на каждый вопрос CLI использовал только вопрос и полный JSON-текст соответствующей MCP-выдачи.

Временные результаты конкретного запуска: `/tmp/opencode/terra20-retrieval4/{run.json,score.json,payloads/}` и `/tmp/opencode/terra20-answers.json`. Они **не входят** в коммит и могут исчезнуть; для независимой проверки текста отдельных ответов или refs их следует воспроизвести. Отчёт хранит итоги и ограничения, а не объявляет временные пути постоянными артефактами доказательства.
