Authorship: fictional manuals written by the calibration agent on 2026-11-06.
These sources are authoritative only within this synthetic evaluation. They are
not externally sourced operational guidance or an external benchmark.

Calibration families: apiary hive movement; museum textile quarantine.
Validation families: underground radio checks; rye sourdough fermentation.
No document or task family appears in both splits. The authored structural
challenge patterns intentionally overlap; this limits generalization and does
not imply exchangeability or statistical coverage.

Inputs were authored without consulting old validation outputs, holdout details
or Terra answers for tuning. The new cases target the proposed general mechanism:
contextual relevance can leak from ancestor introductions into unrelated own
bodies. Generic document roots, broad procedure scopes, useful child bodies and
unrelated siblings are all labelled independently. Cases also cover unlinked
exception siblings, whole procedure/subtree requests, long irrelevant prefixes
before tail facts, Russian original/English translation lanes and no-answer
questions. All nonempty own-body sections are labelled for every question.

Usefulness is semantic evidence usefulness, not delivery membership. A generic
handbook introduction is negative when it supplies no requested fact or material
scope qualification. A procedure's scope introduction is positive when it
qualifies the requested operation. Ancestor headings may aid navigation without
their unrelated body becoming a positive. Structural closure can deliver negative
units; this is measured as overinclusion, not relabelled as useful.

`manifest.json` binds documents, questions, exhaustive labels and this provenance
before inference. Required facts are authored from these independent sources.
Only source documents and a finite catalog enter the isolated prepared project;
labels never enter production retrieval, scoring, closure or validation.

Calibration uses the minimum combined score of every useful unit, then freezes
that policy before fresh validation. Validation cannot change the threshold.
Recipe identifiers must explicitly distinguish the contextual/body gate from
v1; precise aggregation and heading-context semantics must be recorded before
the first public run. The runner uses real public preparation and context calls,
with a passive same-call observer. It never calls the scorer directly.
