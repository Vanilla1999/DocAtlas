# Meridian scheduler

Meridian schedules shared observatory instruments. Reservation rules below concern confirmed night-time observations, not daytime training sessions.

## Services

The reservation service accepts requests, a planner assigns intervals, and an instrument gateway executes approved schedules. The calendar displays plans but cannot authorize execution.
