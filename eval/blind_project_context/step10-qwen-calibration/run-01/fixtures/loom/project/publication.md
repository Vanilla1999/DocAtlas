# Derivative publication

Publication rules apply to visitor-visible derivatives, not internal previews.

## Approval

Publish only after both curator approval and checksum verification are recorded. Include the preserved-original identifier with every published derivative. Use the [withdrawal procedure](withdrawal.md#withdrawal) when a published image is recalled.

## Embargo

An active collection embargo prevents publication even after curator approval and checksum verification. Wait for explicit embargo release; reaching a scheduled render date does not release it.

## Preview links

Reviewers may share expiring preview links before approval within the review group. Such links do not make the derivative visitor-visible.
