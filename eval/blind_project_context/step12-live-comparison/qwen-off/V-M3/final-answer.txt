Before executing a schedule, the gateway compares instrument time with the observatory reference. If the **absolute offset exceeds two seconds**, it must pause schedule execution, notify the duty operator, and leave queued reservations unchanged. It may resume only after **two consecutive reference checks** each report an offset within two seconds. [ev-f60304319cbf91145a36188b, `clock.md:1–4`; ev-b12e42ea1df39ecdd13a0e6f, `clock.md:5–8`]

If the reference clock is unavailable, execution must remain paused; a local clock reading alone cannot satisfy either recovery check. [ev-40bd605ce77a5db0943e7c87, `clock.md:9–12`] The gateway must not use the retired prototype’s recovery behavior of clearing pending reservations and restarting on the first local clock sample. [ev-9067c8cd4b8511716c02cbec, `architecture.md:9–11`]
