# Сокращённый опыт GPT-6.1 Terra

Дата: 2026-11-08. По просьбе владельца исходный план сокращён до четырёх вопросов
и 16 генераций: current, rule-contract-v1, evidence-led-v1, source-revision-v1.
Все отвечающие сессии явно запрошены с `openai/gpt-6.1-terra`, без effort override.
Это **не подтверждённый Terra Low**, не retrieval/MCP/native-client acceptance.
Предыдущий опыт в родительском каталоге сохранён отдельно и в эти цифры не входит.

## Итог независимой оценки

**Локальный выигрыш одношаговых вариантов — один факт; отдельная редактура
ничего не восстановила. Default остаётся current.**

| Вариант | Полностью / 16 фактов | Частично | Отсутствует / противоречит | Корректное воздержание |
| --- | ---: | ---: | ---: | ---: |
| current | 14 | 2 | 0 / 0 | 1/1 |
| rule-contract-v1 | 15 | 1 | 0 / 0 | 1/1 |
| evidence-led-v1 | 15 | 1 | 0 / 0 | 1/1 |
| source-revision-v1 | 14 | 2 | 0 / 0 | 1/1 |

Это 16 требований в трёх ответных вопросах (8 + 7 + 1), не 16 независимых
вопросов. Четвёртый вопрос — корректное воздержание без искусственного факта.
Всего оценены 64 fact-verdicts и четыре ответа без фактов. Частичные не зачтены
как полные; исходный знаменатель сохранён.

Различия сосредоточены в V-M1:

- **Все четыре варианта** описывают остановку как уже произошедшую:
  «Если наружные наблюдения приостановлены…». Это не явная обязанность остановить
  наблюдения при размыкании ветровой блокировки. `V-M1-fact-6` везде partial по
  прежней шкале. Связь этого правила с вопросом о передаче пограничная; она
  отмечена отдельно, но не использована для улучшения оценки задним числом.
- `current` и revision сохраняют ID **при передаче**, но не говорят о сохранении
  ID **во время погодной приостановки**: `V-M1-fact-7` partial. Новые одношаговые
  варианты содержат «идентификатор бронирования при приостановке сохраняется»:
  этот факт full. См. [trial-001](answers/trial-001.md),
  [trial-002](answers/trial-002.md), [trial-003](answers/trial-003.md),
  [trial-025](answers/trial-025.md).
- У current и revision вводная область применимости поддержана источником, но
  соответствующий диапазон `reservations.md:1–6` явно не процитирован.
  Оценщик отметил неполное покрытие ссылками, не выдуманный факт.
- Неподдержанных добавлений оценщик не обнаружил. У части ответов отмечены
  подтверждённые, но периферийные подробности о календаре/учебных слотах.

Новая процедура печати получила 7/7 во всех вариантах, лимит вложения — 1/1.
В вопросе о сроке удаления все четыре ответа ограничили отсутствие сведений
предоставленным источником и не приняли период сверки устройств за срок хранения.

Источник результатов: [необработанная слепая оценка](assessment.json),
[машинная сводка](assessment-summary.json). Сводка проверила комплектность,
точное совпадение цитат с ответами и сохранение первых восьми оценок при
восстановлении усечённой доставки. Это отдельная LLM-сессия, не человеческий
review. [Первоначальная неполная оценка](assessment-partial.json) тоже сохранена.

## Решение

Два opt-in варианта остаются гипотезами. Этот прогон даёт один положительный
пример сохранения временной области, но не доказывает общего превосходства.
Новый synthetic материал дал одинаковые результаты во всех вариантах — там
baseline уже достиг потолка. Revision не исправил два partial, хотя использовал
дополнительную стадию и больше сгенерированного текста. Не включаем его в клиент
и не меняем default. Новых формулировок под увиденные ответы не подбирали.

Вопросы, источники, исходный gold и одношаговые prompts не менялись. Все 16
генераций завершились с первой попытки; каждый результат сохранён, без отбора.
Сравнение парное по одинаковым источникам, но по одному ответу на вариант:
изменчивость модели и статистическая значимость не измерены. Три новых вопроса
синтетические, единственный прежний вопрос — development-задача. При сокращении
исключены остальные вопросы до генерации, поэтому выводы не относятся ко всем
восьми исходным задачам.

## Размер текста, не токены или цена

| Вариант | Финальных слов, 4 ответа | Слов с учётом черновиков | Логических ответных стадий |
| --- | ---: | ---: | ---: |
| current | 322 | 322 | 4 |
| rule-contract-v1 | 267 | 267 | 4 |
| evidence-led-v1 | 314 | 314 | 4 |
| source-revision-v1 | 327 | 649 | 8 |

Источник: [text-metrics.json](text-metrics.json), слова считаются через whitespace
split, включая оформление ссылок. Revision повторно использует четыре ответа
current: реально получено 16 финальных ответов, а не 20 независимых генераций.
Стадии не равны provider requests: загрузка входа и внутренняя оркестрация могут
добавлять обращения. Provider tokens, cache usage, latency и стоимость неизвестны.

## Проверка tooling

`study.py summarize --run-dir .../terra-small` принял полный комплект. Пять
повреждённых копий были отклонены, сводки для них не созданы: пропущенный roster,
изменённый revision prompt, изменённый baseline, отсутствующий revision answer,
изменённая sealed baseline-копия. См. [integrity-checks.json](integrity-checks.json).
Воспроизведение prompt из manifest/case/источников/черновика закрывает замечание
review; сравнение файловых hashes не является единственной проверкой.
Неизменность входов и source spans проверена отдельно в
[artifact-checks.json](artifact-checks.json). Новых тестовых сценариев в suite нет.

Git-коммиты фиксировали стадии локально; публичная отправка произошла позднее.
Полная трасса дочерних tools и server-side model metadata недоступны: см.
RUN_RECEIPT_RU.md. Передача gold отсутствует в сформированном задании, но sandbox
с технически запрещённым доступом к gold не создавался.
