# Сокращённый опыт Terra: поправка до генерации

Дата: 2026-11-08. Пользователь после review попросил: «поменьше сделай и пусть это terra будет».

Вместо первоначальных 32 генераций проводим 16: четыре вопроса × четыре
варианта. Это отдельная сокращённая выборка, не выполнение полного исходного
плана. Выбор до генерации: V-M1 (первая прежняя процедура),
fresh-en-print-queue-recovery (первая новая процедура),
fresh-en-single-attachment-limit (короткий факт),
fresh-ru-undocumented-journal-retention (нет ответа). Оставляем русский и
английский, прежний и новый материал. Вопросы, источники, gold и prompts
копируются из первоначального freeze без редактирования; сохраняются trial ID.
Исключённые вопросы не считаются неудачами или успехами.

Модель отвечающих сессий: `openai/gpt-6.1-terra`, явно выбранная пользователем.
Вариант effort не переопределяется. Это не свидетельство режима Terra Low.
Модель обнаружена в каталоге текущего harness. Исполнение — свежие general
subagent sessions, без передачи истории родителя. Каждая получает только путь
к отдельному текстовому prompt, читает его один раз и отвечает без других tools.
Служебные инструкции harness могут присутствовать; это не bare provider API.
Gold, название варианта и другие ответы в файл задания не включаются.
Revision получает только предписанный черновик current и прежние источники.
Сбой сессии фиксируется как сбой; автоматических повторов и выбора лучшего нет.

Перед генерацией фиксируются этот документ, roster, входы, модель и hashes.
После 12 первых ответов они сохраняются и коммитятся; затем фиксируются четыре
revision-входа и их seal, после чего запускается revision. Все 16 результатов
коммитятся до независимой оценки. Ответы сохраняются дословно вместе с session ID.
Provider usage, фактическое число внутренних requests и стоимость остаются null,
если инструмент их не сообщает. Размер текста — не токены.

Одна свежая независимая сессия оценки (модель harness по умолчанию) получает
перемешанные анонимные ID, ответы, вопросы, источники и исходный gold. Не получает
названия вариантов, prompts, session ID и соответствие trial ID. Оценка:
full / partial / missing / contradicted по каждому факту с цитатой, отдельно
неподдержанные утверждения, ссылки, релевантность и корректное воздержание.
Самооценка генератора не используется. Это независимая сессия, не человеческий
review и не гарантия объективности LLM-оценки. Все оценки публикуются.

Исправление tooling после review: study.py теперь проверяет полный revision
roster, пересобирает prompt из замороженных источников/инструкции/черновика,
проверяет фактические hashes и запрещает изменение одношаговых ответов после
подготовки revision. Исходный manifest обновляет только hash study.py и явно
ссылается на первоначальный commit; исходные prompts/gold не меняются.
Новые unit/integration-тесты не добавляются. Проверяется CLI на артефактах опыта;
повреждённые копии используются только для проверки отказа сборщика сводки.

Вывод ограничен этими четырьмя вопросами и одним ответом на вариант. Нет
статистической значимости, product acceptance или оснований менять default.
