# Парное сравнение Mini / budget: протокол до результатов

База: `a5e7e9dda1bc45be8de89006af3f062fd8362d2d`, ветка
`fix/main-flow-compact-evidence`. Основание запуска — новая просьба владельца
реализовать режим с моделью V2 и без модели и выполнить 40 вопросов после
улучшения этапа до ранжирования. Окончательная фиксация файлов и времени —
`attempt-01/RUN_MANIFEST.json` перед первым модельным и продуктовым вызовом.

## Проверяемое различие

Общий поток: prepared source structure → существующий retrieval →
`source_valid_candidates_v1` → одинаковый проверенный native pool → выбранный
selector → существующая сборка и все конечные проверки → публичный JSON.

`budget` выбирает первые `k=2` кандидата существующего порядка; `mini` выбирает
два по raw logits прежнего V2 `mmarco-mMiniLMv2-L12-H384-v1`, точная revision
`1427fd652930e4ba29e8149678df786c240d8825`. Кандидаты, права и содержание не
меняются моделью. `k=2` сохранён из V2 до просмотра новых результатов. Общий cap
всего JSON — 12000 по максимуму UTF-8/4 proxy и named codec o200k_base. Это
лимит native selection, а не обещание ровно двух конечных source rows.

Новая реализация не добавляет правила чисел, названий продуктов, заданных
вопросов или частей эталона. Автор model provider не читал V40 вопросы и oracle.
Существующий V3 scalar-label режим не выбран. Defaults не изменяются.

## Полный корпус и независимый эталон

Используются все 40 исторических V40: 24 positive, 8 partial, 8 unanswerable,
по 8 на Black/Poetry/Textual/Vite/ESLint. Восстановлены 15 исходных документов
ровно pinned commits. Gold и вопросы скопированы побайтово. Это **открытый
исторический набор**, не новый независимый holdout и не прежние 39/40 фактов.
Ограничения исходного gold зафиксированы в `CORPUS_RU.md` до запуска.

Основная мера — доставка полного исходного gold witness в объединении snippets
нужного source. Допускается только trim внешнего whitespace witness. Отдельно
считается документированная часть partial. Неподтверждённая часть не считается
доставленной. Для unanswerable сохраняется строгий empty-source контракт.
Семантическая достаточность, релевантность и точность будущего ответа не выводятся
из score, source hash, `coverage` или успешного выполнения процесса.

## Ограниченный запуск

- 5 настоящих `prepare_docs`, prepared flag включён до индексации.
- 40 пар, ровно один `get_docs_context` в каждом режиме на каждом вопросе:
  всего 80. Никаких дополнительных capture/read или source continuation.
- Одна холодная подготовка resident Mini без readiness forward. По одному
  forward на native candidate только в подходящих Mini pools. Генератор — 0.
- Полный вход каждой пары проверяется до первого forward. Если любой кандидат
  превышает 512 токенов, весь Mini pool возвращается к budget и получает явный
  статус `budgetfallback_overflow`; это не model-scored сравнение.
- При `pool <= 2` модель не нужна: `not_needed`, 0 forward. Ошибки не получают
  скрытого fallback. Повторы автоматически не выполняются.
- Максимум 60 секунд на context call, 180 на индексацию, 120 на загрузку Mini.
  Превышение сохраняется как ошибка. Нарушение неизменности состояния останавливает
  оставшиеся вызовы. Неравные pools сохраняются как несопоставимые пары.

Arm order чередуется по заранее заданному индексу. Каждая пара использует один
project root, index generation и каталог. Подготовленные source bytes проверяются
независимым чтением generation_sources. Состояние всех SQL tables и source files
сравнивается после каждой пары.

## Сохраняемые доказательства

Полный фактический JSON хранится без дополнительных diagnostic полей.
Трасса и deep-copy observer receipt записываются отдельно: полный упорядоченный
upstream universe, checked pool, исключения, source/span/generation bindings,
выбранные индексы, tokens, logits и затраты. При сравнении pools пока не исключается
ни одного metadata поля: статически не обнаружены per-call nonce/timestamps.

До каждого настоящего действия ledger записывает попытку. Индексация, загрузка,
каждый public call, фактические model forwards и model input tokens считаются
раздельно. Полное traced public wall включает inline tokenization/scoring и
observer. Дочерние model import/hash timings уже входят в model load и не
суммируются с ним дважды. Asset download/install сохранены отдельными receipts,
включая первую неуспешную попытку HF CLI из-за отсутствующего `socksio`.

Один процесс держит Mini resident для обеих arms. Поэтому peak RSS — память всего
эксперимента, не сравнение памяти отдельных сервисов. Billing генератора и его
latency не измеряются. Независимый reviewer проверяет соответствие окончательных
snippets вопросам отдельно от автоматического gold-span показателя.

После открытия результатов код, corpus, oracle, модель, k, cap и overflow policy
в этом цикле не меняются ради улучшения показателей. Исправление инструмента
измерения при обнаруженном дефекте требует явного журнала, сохранения старых
артефактов и указания, нужен ли новый продуктовый запуск.
