# Зафиксированный узкий контракт V3

2026-10-12, до product patch и inference. Координатор принимает предложение A §§3–6 только как opt-in retrieval-only исследование, не изменение default-контракта.

`DOCATLAS_EXPERIMENT_ADMISSION=scalar_label_candidates_v3` наследует B1 unassessed candidate lane. Все source/native/hash/catalog/generation/window/owner/unresolved-name/hard-exact проверки остаются. Старые ordinary/default и `policy_candidates_v1` сохраняют прежнее поведение.

Изменяется только numeric fallback: каждый digit-bearing токен вопроса должен быть самостоятельным unsigned decimal scalar, за которым идёт самостоятельный буквенный label; кандидат требует source-bound scalar+точно общий label в одном masked body block. Decimal comma атомарна; ranges/versions/identifiers/path/exponents/sign/operator expressions не допускаются. Новый witness явно unassessed, без coverage/answer/edit authority. Ни словарей benchmark, ни global cross-document bypass, ни query rewrite.

Уточнение preflight, до inference: запрет ranges/versions/sign/operator относится только к **добавочному scalar-label fallback**. Сначала сохраняется прежний B1 exact numeric route; новый режим не вводит глобальный запрет на уже допустимые exact-supported constructions.

Строгие прежние empty-source expectations НЕ меняются. Nonempty semantic negatives — CURRENT_CONTRACT FAIL, даже при правильном host refusal. Требования source-policy сохраняются без исключений.

Полный multifacet recall без числовых конструкций в contributing blocks этим правилом не решается: это заранее записанный blocker, а не повод ослаблять gates после результата. V2 HOLD03/HOLD05/HOLD06 могут использоваться только как known diagnostics, не новый holdout и не calibration параметров.

A получает владение только `docmancer/docs/domain/original_body_discovery.py` и `docmancer/docs/domain/ordinary_body_context.py`; остальные product файлы не меняет. Runtime/tests/compile/AST не запускает. B остаётся client adapter; C независимо проверяет frozen inputs/contract/outputs.

Mini подключается только при содержательной задаче bounded selection после pool restoration и отдельной calibration. X-prune и прежняя model matrix не исполняются.
