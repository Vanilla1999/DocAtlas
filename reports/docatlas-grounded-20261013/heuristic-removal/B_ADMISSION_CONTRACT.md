# B — source-only admission contract

Status before implementation: candidate only, default OFF. Public contract change / promotion **NOT APPROVED**. No runtime, tests, benchmarks, delegation or commits by B.

## Contract recorded before edits

`DOCATLAS_EXPERIMENT_HEURISTIC_REMOVAL=A` or `ALL` selects source-only admission; Q/S/absent/unknown values retain baseline admission. Domain reads this host environment locally, avoiding a domain-to-application import. The coordinator's application switch must use the same exact values. Keep environment stable for the entire synchronous public call, including projection/rechecks; concurrent mutation is unsupported.

This candidate removes lexical ratios, whole-question names/numbers/phrases/exact-symbol obligations, heading/table lexical rescue and any comma-and decomposition rescue from admission. No replacement parser, dictionary or threshold is introduced. Existing source-locator resolution is retained as a request restriction, not relevance proof. Quoted/body symbols are not source locators unless the existing resolver binds them to a catalog source.

Canonical source checks are mandatory: source policy/access and catalog membership, project/snapshot identity, explicit scope/version/locator, lifecycle/freshness, immutable raw hash/window/owner, live same-call original native receipt, and verified structural derivation at final recheck. The candidate witness is the entire nonempty verified raw window, not a topical/phrase witness. Source validity does **not** promise usefulness, semantic sufficiency, predicate/default/condition truth or an answer.

Qualification remains `qualified=False`, no covered IDs, no coverage kind, `qualification_reason=source_valid_relevance_unassessed`, `relevance_unassessed=True`, `coverage_credit=False`, `context_only=True`. Incoming qualification/lexical diagnostic fields cannot confer credit. Admission/recheck retain the existing signatures and route `source_valid_unassessed`; witness kind remains `source_valid_original_candidate_v1`, with `admission_contract=source_only_heuristic_removal_v1`. Answer support/availability/edit authority must remain false downstream.

## Negative contract and approval boundary

Historical negative **strict `sources=[]`** remains the unchanged metric/oracle. Nonempty authentic but irrelevant sources are FAIL, not reclassified as PASS or a correct refusal. Source-only admission does not enforce semantic abstention; it may worsen this metric. Unknown/foreign/ambiguous explicit locators, unauthorized scope/version, stale/raw-mismatched sources and nonlive/forged native receipts must still reject. Absence of a whole-query symbol/numeric/phrase witness alone no longer rejects candidate context.

ADR0003's literal/exact/name/numeric admission promises are not silently amended. This is an isolated experimental deviation awaiting an explicit owner decision and public integration evidence, not a production fix. Qualification is deliberately not converted to true to facilitate admission.
