## Purpose

P2.2A defines the execution boundary for the Product Truth comparison without weakening the P2.1 task-validity gate.

The frozen cells are:

| ID | Evidence condition |
|---|---|
| `A_repo_only` | repository and coding tools only |
| `B_repo_plus_docatlas` | repository plus installed DocAtlas bounded evidence |

```text

```


## Harness proof

A provider-free synthetic control builds the exact 16-cell canary shape:

```text
2 tasks × 2 model snapshots × 1 repeat × 4 conditions = 16 runs
```

It verifies:

- exactly one run per condition in every block;
- identical non-evidence invariant hash within each block;
- positions 0–3 used exactly once per block;
- balanced condition positions across blocks;
- exact evidence capability flags.

Seven mutations fail closed on authorization bypass, run injection, capability drift, randomization drift, canary/product claims and cardinality relaxation.
