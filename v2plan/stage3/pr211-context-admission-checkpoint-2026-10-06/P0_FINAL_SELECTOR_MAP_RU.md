## Общая цепочка, без подмены coverage proof

Only mandatory covered requirements receive assignment. One selected covering candidate wins _assignment_preference: witness presence, descending supplied completeness, target identity, canonical authority, lifecycle, version, relevance, witness length, rank, stable ID. Witness spans/hash bind local unit; no-witness assignment binds whole projected candidate. Missing mandatory assignment downgrades status.

status ok iff selected/nonmissing/nonconflicting, with identity/bounds/factual/project requirements and project context-only authorization guards; answer_supported=status==ok. selected_evidence_ids are assigned IDs, satisfied_requirement_ids are coverage IDs (not identical sets). Advisory-only coverage does not authorize a mandatory assignment.

Actual coverage `docmancer/docs/application/_evidence_selection_part03.py:553–680`; witness `docmancer/docs/application/_evidence_selection_part02.py:155–264`; assignment `docmancer/docs/application/_evidence_selection_part03.py:315–440`; support `docmancer/docs/application/_evidence_selection_part03.py:441–475`. Для обычных library/generic facets/code_group возможен whole-candidate assignment **без local unit witness**. Для factual-only project нужен witness. Advisory source_fact может покрыться, но mandatory assignment не получает.
